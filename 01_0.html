資通安全管理法適用對象完整說明

關於納管對象

資通安全管理法明確規範了適用對象與範圍，包括公務機關、特定非公務機關及關鍵基礎設施提供者。本頁面詳細說明各類納管對象的認定標準、適用條件及相關責任。

資通安全管理法(資安法)的納管對象主要分為三大類:

1. 公務機關
  • 中央機關: 總統府、五院及所屬各級機關
  • 地方機關: 直轄市政府、縣市政府、鄉鎮市區公所
  • 民意機關: 各級民意機關(立法院、議會等)
  • 司法機關: 各級法院及檢察機關
2. 特定非公務機關
  • 公營事業: 政府持股或控制≥50%的事業
  • 政府捐助之財團法人: 政府捐助≥50%且具公共性質
  • 行政法人: 依法設立的行政法人
  • 政府委託行使公權力之團體: 受託辦理特定公務的民間組織
3. 關鍵基礎設施提供者(CII)
  • 能源: 電力、石油、天然氣供應業者
  • 水資源: 自來水、水庫管理單位
  • 通訊傳播: 電信業者、廣播電視業者
  • 交通: 鐵路、航空、港口、公路運輸業者
  • 金融: 銀行、證券、保險業者
  • 緊急救援與醫院: 大型醫療院所、緊急救護體系
  • 高科技園區: 科學園區管理局及重要廠商
  • 政府機關與國防: 國防相關單位與設施
⚠️ 重要: 各主管機關會定期公告並更新納管對象名單，建議定期至數位發展部資通安全署官網查詢最新資訊。

「特定非公務機關」是指雖非政府機關，但因與政府關係密切或執行公共任務，而被納入資安法規範的組織。

認定標準包括:
  • 政府捐助之財團法人:
    • 政府捐助財產總額達50%以上
    • 由政府指派董事、監察人席次達1/2以上
    • 具公共性質或執行政府委辦業務
  • 政府持股/控制之事業:
    • 政府持股比例達50%以上
    • 或政府實質控制其經營權
  • 行政法人:
    • 依特別法設立(如國家表演藝術中心、國家災害防救科技中心等)
    • 具公法人地位但運作較具彈性
✓ 實務案例:
  • 納管: 中華郵政、台灣電力公司、中油公司、台糖公司(政府持股100%)
  • 納管: 工業技術研究院、資訊工業策進會(政府捐助≥50%)
  • 不納管: 純民間企業(即使承接政府標案)
⚠️ 注意: 若不確定是否為特定非公務機關，可向主管機關(如經濟部、數位發展部)或數位發展部資通安全署查詢確認。

「受政府控制之事業」是指政府透過持股、人事任命或其他方式，實質掌握經營決策權的事業體。

界定標準:
  • 持股比例: 政府直接或間接持有股份達50%以上
  • 董事席次: 繼續完成剩餘的HTML程式碼： ```html 政府指派或實質控制董事會過半數席次
  • 經營決策權: 政府對重大經營決策具有決定性影響力
  • 預算依賴: 主要經費來源為政府預算或補助
✓ 典型案例:
  • 公營事業: 台電、中油、台水、台糖(政府持股100%)
  • 國營事業: 中華郵政、台灣菸酒(政府全資擁有)
  • 政府投資事業: 中華電信(政府持股35%但具實質影響力)
⚠️ 判斷重點:
  • 不僅看持股比例，更要看實質控制能力
  • 政府若能主導董事會決議，即使持股未達50%仍可能被認定
  • 特許事業(如電信、能源)即使民營化，仍可能因公共性而納管
📌 實務建議: 若事業體與政府有投資或業務關係，建議主動向經濟部或數位發展部確認是否屬於納管對象，以免因不知情而違法。

關鍵基礎設施提供者(Critical Information Infrastructure, CII)是指其資通系統或服務一旦遭受破壞，將嚴重影響國家安全、社會秩序或公共利益的組織。

八大領域認定標準:
  • 1. 能源領域:
    • 發電量達一定規模的電力公司
    • 石油、天然氣儲運設施營運者
    • 再生能源重要供應商
  • 2. 水資源領域:
    • 供水人口達一定規模的自來水公司
    • 重要水庫、淨水廠管理單位
  • 3. 通訊傳播領域:
    • 第一類電信事業(中華電信、台灣大哥大等)
    • 主要ISP業者、數據中心營運商
    • 重要廣播電視業者
  • 4. 交通領域:
    • 台鐵、高鐵、捷運系統
    • 主要國際機場、商港
    • 高速公路管理單位
  • 5. 金融領域:
    • 系統性重要銀行(如台銀、兆豐等)
    • 證券交易所、期貨交易所
    • 票據交換所、財金資訊公司
  • 6. 緊急救援與醫院:
    • 醫學中心及區域教學醫院
    • 119緊急救護指揮中心
    • 重要血庫、疫苗儲存設施
  • 7. 高科技園區:
    • 竹科、中科、南科管理局
    • 園區內重要半導體、電子廠商
  • 8. 政府機關與國防:
    • 國防部及所屬單位
    • 關鍵政府資訊系統營運機關
✓ 認定程序:
  1. 由各目的事業主管機關(如金管會、交通部)初步評估
  2. 報請數位發展部審查認定
  3. 正式公告為關鍵基礎設施提供者
  4. 定期(每2年)檢討調整名單
⚠️ 重要: CII業者須遵守更嚴格的資安規範，包括強制通報、定期演練、專責人力配置等，違反規定可處100萬元以上罰鍰。

私立學校原則上不適用資安法，但有例外情況。

適用情況分析:
  • ❌ 原則不適用:
    • 一般私立大專院校
    • 私立高中職、國中小
    • 私立幼兒園
  • ✅ 例外適用情況:
    • 受託辦理政府委辦業務時(如招生考試、學籍管理系統)
    • 使用政府補助經費建置的資通系統
    • 與公立學校共用的重要資訊系統
✓ 實務案例:
  • 不適用: 私立大學的校務行政系統(自行建置營運)
  • 適用: 承辦大學入學考試的私校(受託行使公權力)
  • 適用: 使用教育部補助建置的學習歷程檔案系統
⚠️ 注意事項:
  • 雖不直接適用資安法，但仍須遵守個資法規定
  • 教育部可透過補助或評鑑要求私校提升資安水準
  • 建議參考資安法標準建立校內資安管理機制
📌 建議: 私立學校雖非強制納管，但因涉及大量師生個資，建議主動參考資安法規範，建立適當的資安防護措施。

公營事業與國營事業在法律定義、組織型態上有所不同，但在資安法下均屬納管對象。

定義與差異:
項目 國營事業 公營事業
定義 中央政府100%持股 政府持股≥50%
法源 國營事業管理法 各事業組織條例
典型案例 台電、中油、台水、台糖 中華電信、兆豐銀行
人事制度 適用國營事業人員進用規定 依公司法或各別法規
監督機關 經濟部(多數) 各主管機關
✓ 資安法適用情況:
  • 兩者均屬「特定非公務機關」
  • 均須遵守資安法完整規範
  • 責任等級由主管機關核定(通常為B或C級)
  • 須設置資安長、資安專責單位
  • 須編列資安預算(占資訊預算7-12%)
⚠️ 特殊考量:
  • 國營事業: 因涉及民生必需(水電油氣)，多同時為CII，資安要求更嚴
  • 公營事業: 若涉及金融、通訊領域，也可能被認定為CII
  • 民營化事業: 即使政府持股降至50%以下，若仍具關鍵性，可能持續納管
📌 結論: 無論是國營或公營事業，在資安法下的基本責任相同，差異主要在於責任等級認定與是否同時為CII。

行政法人與財團法人在法律性質、設立方式、監督機制上有顯著差異，在資安法的適用條件也不同。

✓ 資安法適用情況:
  • 行政法人:
    • 全部納入資安法規範(無條件適用)
    • 案例: 國家表演藝術中心、國家災害防救科技中心、國家運動訓練中心
    • 責任等級通常為B或C級
  • 財團法人:
    • 僅「政府捐助≥50%」者適用
    • 案例: 工研院、資策會、外貿協會
    • 責任等級依業務性質核定
⚠️ 判斷要點:
  • 行政法人: 查看是否有專門的組織法(如「國家表演藝術中心設置條例」)
  • 財團法人: 需確認政府捐助比例，可查詢「全國法規資料庫」或主管機關公告
  • 混合型態: 部分組織可能同時具備兩種性質，以法律明文規定為準
📌 實務建議: 若不確定組織屬性，可至數位發展部資通安全署網站查詢「資安法適用對象名單」，或向主管機關確認。

承包政府標案的一般民間廠商原則上不直接適用資安法，但須遵守契約中的資安要求。

適用情況分析:
  • ❌ 不直接適用資安法:
    • 純民間企業身分的承包商
    • 僅因承接政府標案而與政府往來
    • 政府持股或控制未達標準
  • ✅ 須遵守契約資安規範:
    • 政府採購契約中的資安條款
    • 資通安全責任等級分級辦法相關要求
    • 特定領域的資安標準(如個資法、金融資安規範)
✓ 契約常見資安要求:
  • 資安管理制度: 需建立符合ISO 27001或同等級的資安管理制度
  • 人員管理: 簽署保密協定、背景調查、離職管制
  • 系統安全: 弱點掃描、滲透測試、安全性更新
  • 資料保護: 加密傳輸、存取控制、備份機制
  • 事件通報: 發生資安事件須於規定時間內通報機關
  • 稽核配合: 接受機關或第三方的資安稽核
⚠️ 特殊情況:
  • 受託行使公權力: 若受託辦理具公權力性質業務(如戶政系統維護)，可能被認定為適用對象
  • CII供應商: 若為關鍵基礎設施的重要供應商，可能被要求比照CII標準
  • 長期委外: 長期負責政府核心系統營運的廠商，可能面臨更嚴格要求
📌 實務建議:
  • 投標前詳閱契約資安條款，評估成本與能力
  • 建議取得ISO 27001認證，提升競標優勢
  • 建立資安事件應變機制，確保能即時通報處理
  • 定期教育訓練，提升員工資安意識

有多種官方管道可查詢機關(構)是否為資安法納管對象及其責任等級。

官方查詢管道:
  • 1. 數位發展部資通安全署官網:
    • 網址: https://www.nics.nat.gov.tw
    • 查詢路徑: 首頁 → 資安法專區 → 納管對象名單
    • 提供完整的A至E級機關(構)名單及責任等級
  • 2. 目的事業主管機關:
    • 經濟部: 公營事業、工業相關
    • 金管會: 金融機構
    • 交通部: 運輸、通訊業者
    • 教育部: 公立學校
    • 衛福部: 醫療機構
  • 3. 機關內部資安窗口:
    • 詢問機關內資訊部門或資安專責單位
    • 查閱機關資通安全維護計畫
✓ 自我判斷步驟:
  1. 確認組織性質:
    • 是否為政府機關? → 是 → 適用資安法
    • 是否為公營/國營事業? → 是 → 適用資安法
    • 是否為行政法人? → 是 → 適用資安法
    • 是否為政府捐助≥50%的財團法人? → 是 → 適用資安法
  2. 查詢官方名單: 至資安署網站確認是否列入納管對象
  3. 確認責任等級: 查看公告的A至E級分類
  4. 了解具體要求: 下載該等級的資安規範文件
⚠️ 常見疑問處理:
  • Q: 名單上找不到我的機關?
    A: 可能屬於較大機關的附屬單位,以上級機關等級為準,或直接向主管機關確認。
  • Q: 機關改組後等級是否改變?
    A: 需重新核定,應主動向主管機關申請等級認定。
  • Q: 私人企業如何確認?
    A: 除非是CII或政府持股≥50%,否則一般不適用。

新成立的機關(構)自成立日起即適用資安法,但有合理的緩衝期以建置必要的資安機制。

適用時程說明:
  • 立即適用事項(成立日起):
    • 資安事件通報義務
    • 基本資安防護措施(防火牆、防毒軟體等)
    • 人員資安意識要求
  • 6個月內完成:
    • 指定資安長及專責人員
    • 訂定資通安全維護計畫
    • 建立資安管理組織架構
  • 1年內完成:
    • 完成資安健檢或稽核
    • 完成資安演練
    • 建立完整的資安管理制度
✓ 建議作法:
  1. 籌備期(成立前):
    • 於籌備階段即規劃資安組織與預算
    • 參考同等級機關的資安維護計畫
    • 預先培訓資安專責人員
  2. 成立初期(0-6個月):
    • 向主管機關申請責任等級核定
    • 建立資安管理制度文件
    • 採購必要的資安設備與服務
  3. 穩定期(6-12個月):
    • 執行首次資安演練
    • 完成首次資安稽核
    • 依稽核結果改善缺失
⚠️ 特別注意:
  • 不得以「新成立」為由拒絕通報資安事件
  • 若因組織改造而成立,應承接原機關的資安責任
  • CII業者即使新成立,仍須立即符合較高標準
  • 可向主管機關申請輔導資源或專案協助
📌 實務案例:
  • 數位發展部(2022年成立): 於成立前即完成資安組織規劃,成立日起立即運作。
  • 新設立的行政法人: 通常在籌備階段即納入資安規劃,確保成立時能符合基本要求。
  • 縣市合併後的新機關: 承接原機關資安責任,並於合理期間內完成整合。
💡 資源協助:
  • 數位發展部提供「資安輔導團」協助新機關建置
  • 可參加資安署舉辦的「新手機關資安訓練班」
  • 可申請「資安經費補助計畫」減輕初期負擔
